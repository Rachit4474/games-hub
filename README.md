## How to deploy

1. Create a new public repository named `games-hub` (or any name you prefer).
2. Upload all files in this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Source: Deploy from a branch → `main` → `/ (root)`.
5. Save. Wait ~1 minute.
6. Your hub will be live at `https://rachit4474.github.io/games-hub/`.
